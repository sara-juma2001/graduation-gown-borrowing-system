# Graduation Gown Borrowing System

A web-based system for managing graduation gown borrowing at University of Technology and Applied Sciences – Shinas.

## Features
- Graduate eligibility and login
- Gown size selection
- Borrowing request submission
- Admin approval and rejection
- Gown inventory management
- Return management
- Request status tracking
- Notifications

## Technologies
- HTML
- CSS
- JavaScript
- PHP
- MySQL

## Note
This repository is a recreated portfolio version based on the original Graduation Gown Borrowing System project idea. The original source code is no longer available.
