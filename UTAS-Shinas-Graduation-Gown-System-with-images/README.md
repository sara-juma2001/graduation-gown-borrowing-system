# UTAS Shinas – Graduation Gown Borrowing System

A recreated portfolio version of a graduation gown borrowing system based on the original project idea.

## Features
- Graduate eligibility/login
- Gown size selection (S / M / L)
- Borrowing request submission
- Admin approval/rejection
- Inventory tracking
- Return management
- Notifications
- Student request status tracking

## Technologies
HTML, CSS, JavaScript, PHP, MySQL

## Note
This repository is a rebuilt portfolio version based on the original project concept; it is not the original source code.
